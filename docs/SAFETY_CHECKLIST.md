# 安全检查清单

本项目涉及电池、大电流负载和无线通断控制，测试时请优先保证人员与设备安全。

## 上电前

- 检查电池输入正负极、保险丝或保护路径、MOSFET 方向和大电流焊盘。
- 确认 3.3V、5V、OLED、NRF24L01 和检流芯片没有短路。
- 初次上电使用限流电源，不直接接入满电动力电池。
- 负载端先使用可控假负载，不直接连接危险执行机构。

## 调试中

- 远程开关动作前确认周围人员远离高功率负载。
- 持续观察电流、电压、功率显示和 MOSFET 温升。
- 无线链路不稳定时，不要把本项目作为唯一安全断电手段。
- 发现异常发热、异味、显示异常或电流突增时立即断电。

## 发布前

- 在 README 或 Issue 中公开已验证的电压、电流和负载范围。
- 未验证的极限参数不要写成承诺值。
- 与安全相关的缺陷应优先修复或明确标注为已知问题。
